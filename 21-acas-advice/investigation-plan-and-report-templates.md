# Investigation plan and report templates

_Source: Acas — https://www.acas.org.uk/investigation-plan-and-report-templates_

Acas templates for a disciplinary or grievance investigation plan and report. Free to download and use.

## Investigation plan

To help anyone investigating a disciplinary or grievance to set out:

- the main issues
- what information to gather
- relevant witnesses
- proposed time frames

[Investigation plan template (Word version, 14KB)](https://www.acas.org.uk/sites/default/files/2026-08/investigation-plan-template.docx)

[Investigation plan template (OpenDocument Text format, 8KB)](https://www.acas.org.uk/sites/default/files/2026-08/investigation-plan-template.odt)

## Investigation report

To help anyone investigating a disciplinary or grievance to set out:

- the terms of reference
- the context of the investigation
- witness statements
- findings
- recommendations, where they've been asked for them

[Investigation report template (Word version, 15KB)](https://www.acas.org.uk/sites/default/files/2026-08/investigation-report-template.docx)

[Investigation report template (OpenDocument Text format, 10KB)](https://www.acas.org.uk/sites/default/files/2026-08/investigation-report-template.odt)
