# Job description templates

_Source: Acas — https://www.acas.org.uk/job-description-templates_

Templates to help you write job descriptions. Free to download and use.

[Find out more about hiring staff](https://www.acas.org.uk/recruitment "Recruitment")

If you need the templates in a different format, or you cannot download them, email [digital@acas.org.uk](mailto:digital@acas.org.uk)

## Outline job description

An outline job description including:

- the main headings to use
- the role's main duties
- who the employee will report to

[Job description template (OpenDocument Text format, 6KB)](https://www.acas.org.uk/sites/default/files/2026-08/job-description-template.odt)
