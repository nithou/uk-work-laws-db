Published 27 April 2003

### About this Code

This Acas Code of Practice provides guidance on the information employers disclose to trade union representatives for collective bargaining.

It applies to public and private sector employers.

It does not apply to collective bargaining between employers' associations and trade unions. However, you might want to follow the guidelines in this Acas Code of Practice.

The statutory provisions in this Acas Code of Practice are in bold type.
