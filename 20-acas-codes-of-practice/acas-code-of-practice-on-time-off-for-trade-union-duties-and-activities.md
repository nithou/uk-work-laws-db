# Acas Code of Practice on time off for trade union duties and activities

_Source: Acas — https://www.acas.org.uk/acas-code-of-practice-on-time-off-for-trade-union-duties-and-activities — updated 30 October 2026_

This Code of Practice is the minimum an employer should follow when managing time off for trade union duties and activities.

## Code of Practice

[Acas Code of Practice on time off for trade union duties and activities](https://www.acas.org.uk/acas-code-of-practice-on-time-off-for-trade-union-duties-and-activities/html "Code of Practice on time off for trade union duties and activities")

Published 30 October 2026

### About this Code

This Acas Code of Practice sets out practical guidance for employers, trade unions and trade union representatives. It covers:

- time off for trade union duties and activities
- time off for training
- the provision of accommodation and other facilities

This revised version applies from 30 October 2026. It replaces the version published in January 2010.
