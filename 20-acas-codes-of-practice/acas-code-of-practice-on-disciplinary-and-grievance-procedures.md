# Acas Code of Practice on disciplinary and grievance procedures

_Source: Acas — https://www.acas.org.uk/acas-code-of-practice-on-disciplinary-and-grievance-procedures — updated 11 March 2015_

The Acas Code of Practice on disciplinary and grievance procedures is the minimum an employer should follow for handling these issues at work.

## Code of Practice

[Acas Code of Practice on disciplinary and grievance procedures](https://www.acas.org.uk/acas-code-of-practice-on-disciplinary-and-grievance-procedures/html "Code of Practice on disciplinary and grievance procedures")

Published 11 March 2015

### About this Code

Employers should follow a fair procedure in line with the Acas Code of Practice for any discipline or grievance case. The procedure an employer follows and an employee's actions will be taken into account if the case reaches an employment tribunal.

The Acas Code of Practice mainly applies to anyone legally classed as an employee. To help working relationships, employers might want to use the same procedure for anyone legally classed as a worker. Find out more about [employment status](https://www.acas.org.uk/employment-status "Employment status").

We will be updating this Code of Practice. We are doing this to promote the early resolution of concerns in the workplace.
