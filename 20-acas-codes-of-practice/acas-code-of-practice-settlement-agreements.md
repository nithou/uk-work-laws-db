# Acas Code of Practice on settlement agreements

_Source: Acas — https://www.acas.org.uk/acas-code-of-practice-settlement-agreements — updated 29 July 2013_

The Acas Code of Practice on Settlement Agreements (under section 111A of the Employment Rights Act 1996).

## Code of Practice

[Acas Code of Practice on settlement agreements](https://www.acas.org.uk/acas-code-of-practice-settlement-agreements/html "Settlement Agreements (under section 111A of the Employment Rights Act 1996)")

Published 29 July 2013

### About this Code

Employers and employees can use a settlement agreement to resolve a problem or to end employment.

This Code of Practice does not apply to making a settlement through Acas early conciliation.
